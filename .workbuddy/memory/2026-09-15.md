### ⭐ 本次形成的新约定（跨会话有效）

**1. 两个快照后缀，语义互不相同，别混用**

| 后缀 | 内容 | 可覆盖性 |
|:---|:---|:---|
| `.crossbrain-backup` | 首次注入前的**原始文件** | **任何代码路径都不得覆盖** |
| `.crossbrain-before-restore` | **最近一次还原前的现场** | 滚动；**仅当现场 ≠ 备份内容时**才写 |

第二条里的「仅当不同」不是优化而是正确性要求：无条件写会让连续第二次还原用
「已还原后的内容」覆盖掉第一次留下的**真实现场**，为「可逆」而做的功能反而造成不可逆丢失。

**2. `Adapter` 新增可选方法 `l0_backup()` —— 默认返回 `None`（第 4 个差异项）**

```rust
fn l0_backup(&self) -> Option<L0Backup> {
    Some(L0Backup { target_file: …, backup_file: … })   // 只有标记块注入型需要覆盖
}
```

返回**一对**路径而非单个备份路径：还原同时需要落点与快照，只给备份路径就得到
「把 `.crossbrain-backup` 去掉反推文件名」——又是一份会分叉的命名规则副本。
给默认实现后，Antigravity 与全部测试 Mock 一行都不用改。
