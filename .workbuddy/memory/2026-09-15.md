### ⭐ 新增的跨会话约定 / 坑

1. **Markdown 预览是安全边界，不是排版问题**。`tauri.conf.json` 的 `csp` 是 `null`，
   webview 里的脚本有 `invoke` 权限——预览若渲染原始 HTML，等于把本地文件读写权交给
   任意脚本。markdown-it 默认 `html:false` 转义原始 HTML（实测 `<b>` → `&lt;b&gt;`），
   因此**严禁打开 html 开关**（`markdown_preview_must_escape_raw_html` 锁死）。
   选 markdown-it 而非 marked+dompurify：单依赖且默认安全。
2. **预览区链接必须拦截点击**（`@click.capture` + preventDefault），否则 webview 导航
   会把应用带离界面。v-html 内容不受 scoped 样式影响 → `.md-preview` 必须放全局 `style.css`。
3. **`n-tab-pane` 默认 `display-directive="if"` 会卸载面板**，编辑类内容（未保存修改）
   跟着丢 → 有可编辑状态的 Tab 一律 `show:lazy`。
4. **`n-message-provider` 必须包在所有视图外层**（App.vue）。放进 `v-if` 分支，
   另一分支的 `useMessage()` 运行时才报错，构建期看不见。
5. **「未保存」按内容基线判断**（`dirty = content !== baseline`），比「敲过键盘」准确：
   改了又改回原样不算未保存，且天然满足向导「没动过不写盘」。
6. **「读不出来 ≠ 空」同样约束编辑器**：baseline 未建立前禁用保存，
   否则用户会用空文件覆盖自己的规则（与 ADR-14 同源）。
7. **主工作台的模板入口只在内容为空时显示**：模板一点就整篇替换，在有内容时显示 =
   静默覆盖用户规则。用「空白才显示」从机制上消灭，而不是靠确认弹窗。
8. 分栏编辑框用**原生 `<textarea>`** 而非 `n-input`：分栏需要固定高度 + 各自滚动，
   `n-input` 的内部高度机制难控，原生 + Tailwind 完全可控。

## 用户反馈布局 BUG 修复（11:33）

- **症状**：初始态输入框下方边框不可见、footnote 被盖（两框缝隙露「推送」）；
  多行输入后面板顶出视口、顶部被盖、textarea 滚不上去。
- **根因**：`<n-spin>` 的 class（flex-1 min-h-0）落在 `.n-spin-container`，
  但插槽层 `.n-spin-content` 高度默认 auto → 内部 `h-full` 的 grid 全部失效，
  窗格高度随内容撑开。**修复：`:content-style="{ height: '100%' }"`（一行）。**
- **教训（重要，通用）**：Naive UI 包裹型组件（n-spin/n-card/n-tab-pane 等）
  会把 flex/grid 的高度链接到自己的 DOM 层就断了——给插槽内容用 `h-full` 时
  必须用 `content-style`/`content-class` 显式接续高度。
- 验证：CDP 几何断言（框高 364 固定、footnote 可见、scrollTop 可设、文档零溢出）
  + 截图；40 行测试内容已回填原文；pnpm build 通过。
