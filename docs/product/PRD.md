---

## 1. 产品定位

**CrossBrain（记忆穿梭）** 的核心价值：**个人全局规则** 与 **按需技能知识** 的跨 AI 工具统一分发。

| 功能类型 | 用户理解 | 行为特征 |
|:---|:---|:---|
| 全局规则 | 编码风格、语言偏好、思维框架 | 每次 AI 对话都自动生效 |
| 技能知识 | 特定领域经验库 | AI 按需加载，不污染上下文 |

> **UI 语言铁律**：L0 / L2 / Adapter / SSOT / slug / frontmatter 等内部研发术语**严禁在任何 UI 界面展示**。对外统一使用「全局规则」与「技能知识」两个词。

---

## 2. 核心特性（V1）

- ✅ **纯本地运行**：所有操作仅涉及本地文件 I/O，零网络依赖，天然支持企业隔离内网
- ✅ **幂等同步**：多次点击同步，结果一致，不产生副作用
- ✅ **保护既有配置**：严禁清空用户现有 AI 工具配置，采用标记块注入或备份策略
- ✅ **孤儿自动清理**：用户删除技能知识后，同步时自动清除所有工具中对应的历史文件
- ✅ **本地版本历史**：基于本地 git 的变更记录（git 未安装时降级，不阻断主流程）

| 工具 | 全局规则推送路径 | 技能知识推送路径 | 实测状态 |
|:---|:---|:---|:---|
| **Claude Code CLI** | `~/.claude/CLAUDE.md`（标记块注入） | `~/.claude/skills/crossbrain-{id}/SKILL.md` | ✅ 实测通过 |
| **Antigravity IDE** | `~/.gemini/config/rules/crossbrain-L0.md` | `~/.gemini/config/skills/crossbrain-{id}/SKILL.md` | ✅ 实测通过 |
| **Gemini CLI** | 共用 `~/.gemini/config/` 体系 | 共用 `~/.gemini/config/skills/` | ✅ 天然顺带支持 |
| **Codex**（OpenAI） | `~/.codex/AGENTS.md`（标记块注入，**内联规则内容**） | `~/.codex/skills/crossbrain-{id}/SKILL.md` | 🔄 2026-09-14 增补，落点已探明 |

> **「Codex」这一行的命名修正（2026-09-14，两次）**：
> 本节原先写作「**ChatGPT IDE**」，属命名错误；第一次更正为「**Codex CLI**」，
> 第二次（同一日探测到用户的桌面安装后）更正为「**Codex**」。
>
> 实测结论：用户机器上装的是 **Codex 桌面应用**（MSIX 包身份 `OpenAI.Codex`，
> 官方 DisplayName 就是 `Codex`，装在 `D:\soft\win-x64`），而**桌面 App、内置 CLI
> 与 Chrome 扩展三者共用同一个 Codex home `~/.codex/`**。官方文档亦确认
> 「在桌面 App 里配置自定义指令，本质上也是写入 Codex home 的 AGENTS.md」。
> 故本工具只有一个落点、一个显示名 `Codex`，**不需要**为「App」「CLI」各做一套。
>
> ⚠️ 另有一条硬约束：`~/.codex/AGENTS.override.md` 的优先级**高于** `AGENTS.md`，
> 它一旦存在就会让 CrossBrain 的规则完全不生效——同步前必须检测，命中即中止报错。
> 任务定义见 `TASK_BREAKDOWN.md` TASK-18。

## 5. 首次运行向导（5 步强制流程）

> **设计原则**：不要求用户理解任何技术细节。每一步只问一件事，每个按钮只做一件事。

### 步骤 1 — 欢迎

```
主标题：CrossBrain 让你的 AI 配置跨所有工具同步生效
副标题：写一次，处处可用。全程在本机运行，无需联网。
唯一按钮：「开始配置」
```

### 步骤 2 — 检测你的 AI 工具

```
展示检测结果（工具清单由后端 `detect_tools` 返回，前端不硬编码）：
  ✅ Claude Code       推送位置：C:\Users\xxx\.claude\
  ✅ Antigravity IDE   推送位置：C:\Users\xxx\.gemini\config\
  ✅ Codex             推送位置：C:\Users\xxx\.codex\
  ⏳ Trae              即将支持（不参与本次同步）

交互细节：
  - 每个已支持工具的推送路径可点击修改（高级用户入口）
  - 网络状态指示：🔴 无网络（同步完全不受影响，版本历史需 Git）
```

### 步骤 3 — 写你的第一条 AI 规则

```
提供 3 个规则模板（点击即填充到右侧编辑器）：
  - 「前端工程师」
  - 「后端 / 全栈开发者」
  - 「通用开发者」

提示文字（编辑器下方）：
  「这段规则会在所有 AI 对话中自动生效，用于告知 AI 你的编码偏好和工作习惯」
```

### 步骤 4 — 一键同步

```
同步进度逐行实时显示：
  正在推送到 Claude Code...      ✅ 完成
  正在推送到 Antigravity IDE...  ✅ 完成

完成摘要：「已将 1 条全局规则同步至 2 个工具」
```

### 步骤 5 — 验证生效（可选）

```
引导语：「请在 Claude Code 新建对话，复制以下内容发送：」
展示测试提示词（一键复制按钮）

两个按钮：
  「已验证，进入主界面」
  「跳过，直接进入」
```

## 6. 主工作台功能

### 6.1 全局规则编辑器

- **左右分栏**：左边写 Markdown 源文，右边实时预览（两者**同时可见**）
- 保存不自动同步（明确分离「编辑」与「同步」动作）；保存入口 = 按钮 + `Ctrl/Cmd+S`
- 保存成功用**轻提示 Toast**，不用弹窗
- 编辑器顶部显示保存状态：`有未保存的修改` / `已保存 · HH:MM`
- 规则模板快捷入口**只在内容为空时显示**（有内容时套模板 = 静默覆盖用户规则）
- 页面顶部状态栏（见 §7）
- ⚠️ 实现约束（2026-09-15 定稿，详见 `TASK_BREAKDOWN.md` TASK-11 实施修正）：
  预览必须转义原始 HTML（当前 `csp: null`，渲染原始 HTML 等于把本地文件读写权交给脚本）

### 6.2 技能知识管理

- 卡片列表视图（展示技能名称 + description 一行摘要）
- **卡片必须同时展示「源文件名」与「注入后的目录名」**
  - 目录名由 slug-hash 算法生成，纯中文文件名会退化成 `crossbrain-item-{hash}`，
    只看目录名无法判断它对应哪一篇知识
  - 这也让「某篇知识到底被推送到了哪个位置」对用户可查（排障用）
  - 依据：ADR-11 的补偿措施（V1 不做拼音转换，可读性代价由 UI 承担）
- 新建技能：默认标题模板 `# [技术/语言] · [具体场景]`
  - 示例：`# Rust · 生命周期与借用检查器常见错误`
- 字数超过 **2000 字** 时，编辑器顶部显示黄色警告条：
  「此技能知识偏长，建议按主题拆分为多篇，有助于 AI 精准加载」
- 每篇技能知识 = 一个具体主题（严禁一篇包含所有经验的大杂烩）

### 6.3 设置页

- 「一键卸载 / 去痕」功能：移除所有注入的标记块与技能目录
- 各工具推送路径的手动修改入口

## 7. 同步状态可视化（主界面顶部常驻状态栏）

```
上次同步：2026-09-14 19:00   ✅ Claude Code   ✅ Antigravity   🔴 离线模式
[立即同步]
```

**状态指示规则**：
- ✅ 绿色：上次同步成功
- ❌ 红色：上次同步失败（点击可查看原因）
- 🔴 离线模式：当前无网络（仅影响多机同步，本地同步正常）
- 若从未同步过，显示「尚未同步」

## 8. 系统错误 → 用户提示翻译表

> **铁律**：严禁将任何系统原始错误码或技术路径暴露给用户。

| 系统层错误 | 用户看到的提示 |
|:---|:---|
| `Permission denied` | 「没有写入权限，请检查目录访问权限」 |
| `Directory not found` | 静默自动创建目录，无感知 |
| 自动创建目录失败 | 「无法创建配置目录，请手动创建后重试」 |
| Git `nothing to commit` | 静默处理，视为成功，不弹提示 |
| Git 未安装 / 不在 PATH | 「未检测到 Git，规则同步正常，版本历史功能暂不可用 [如何安装 Git]」 |
| 无网络连接 | 「当前无网络，规则同步正常，多机同步功能暂不可用」 |
| `CLAUDE.md` 已备份并注入 | 「已将 CrossBrain 规则追加到你的 Claude 配置末尾。原文件已备份至 CLAUDE.md.crossbrain-backup，如需恢复请查看此文件。」 |

## 9. 功能范围边界（V1 明确不做）

| 不做的事 | 原因 |
|:---|:---|
| 从 URL 导入规则 | 防供应链攻击，安全红线 |
| 自动监听文件变动触发同步（Watcher） | V2 功能，V1 用户手动点击同步 |
| 多机同步 UI | V2 功能 |
| 内嵌 libgit2 | V2 功能，V1 依赖系统已安装 git |
| 团队版 / 多人共享 | V3 功能 |
